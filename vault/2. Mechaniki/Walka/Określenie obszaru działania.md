# Cele w obszarach działania

| Obszar               | Liczba celów (zaokr. w górę) |
| -------------------- | ---------------------------- |
| Stożek               | Rozmiar / 3                  |
| Sześcian lub kwadrat | Rozmiar / 1.5                |
| Walec                | Promień / 1.5                |
| Prosta               | Długość / 9                  |
| Sfera lub okrąg      | Promień / 1.5                |
